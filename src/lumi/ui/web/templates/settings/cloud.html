What gets sent to the cloud (when V2 ships)

  • Your transcript for that single turn
  • The system prompt for your current mode
  • Up to the last ~8 turns of conversation history for context
  • NOTHING else by default — no memory store contents, no audit log, no clipboard, no enrolled-voice embedding
